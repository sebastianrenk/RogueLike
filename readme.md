# Terminal Rogue - like

## Symbols
  - @ = Player
  - \# = Wall
  - . = empty space
  - M = Monster
  - X = Goal

## How to play
Move the player with **wasd**.  
You start with a total of 5 lives. 
If you hit a monster you will lose 1 life. 
There is a total of 10 levels. Reach every goal and beat the game!
